
Устройство которое преобразует структурированные события в форматированный текст и отправляет его на выходной порт для дальнейшей обработки другими устройствами.

### Основные возможности

- **Преобразование событий в текст** - конвертация структурированных данных в читабельный формат
- **Шаблонизация вывода** - гибкая настройка формата текста через шаблоны с переменными
- **Цензурирование данных** - маскировка конфиденциальной информации с помощью regexp-правил
- **Переиспользование текста** - отправка результата на выход для подключения к другим устройствам
