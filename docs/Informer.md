Служебное устройство для предоставления дополнительной метаинформации об устройствах в системе.

Настраивается через параметр `devices`, где ключи — идентификаторы устройств сервиса, а значения — произвольные данные (например, локализованные названия, категории, теги и т.п.).

--------

При инициализации проверяет наличие всех указанных устройств в контейнере — при отсутствии хотя бы одного завершает работу с ошибкой.

--------


Через экшен `information` возвращает полный объект devices как есть.

Обычно используется при генерации сервис-файлов для добавления дополнительных данных. 

Эти данные могу упростить отображение в веб интерфейсе и тп. Например, у вас используются `UniversalDI` устройства, которые не имеют привязки к конкретной модели устройства. Вы можете добавить при генерации сервис-файла `Informer` по типу:

```json
    {
        "id": "Informer",
        "type": "vrack2-system.Informer",
        "options": {
            "devices": {
                "UniversalDI1": {
                    "vendor": "owen",
                    "model": "MB210"
                }
            }
        }
    }
```

**Незабывайте**, что если устройство UniversalDI1 не будет найдено внутри контейнера сервиса - сервис не будет запущен и вернет ошибку `V2SYSTEM_DEVICE_NF` - `Device on service not found`
