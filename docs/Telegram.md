Устройство для отправки текстовых сообщений в Telegram через Bot API.

Поддерживает указание режима форматирования (`parse_mode`), например:
- \`MarkdownV2\`
- \`HTML\`
- \`Markdown\`

Для работы требуется:
1. Бот, созданный через [@BotFather](https://t.me/BotFather)
2. Полученный токен (например, \`123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11\`)
3. ID чата/канала (можно получить через [@RawDataBot](https://t.me/RawDataBot) или метод `getUpdates` API)

⚠️ **Важно**: токен — секрет. Не коммитьте его в открытые репозитории.
