
Устройство которое записывает структурированные события в файлы логов с поддержкой форматирования и цензурирования конфиденциальных данных.

### Основные возможности

- **Запись событий в файл** - автоматическое создание лог-файлов с датой в названии
- **Шаблонизация вывода** - гибкое форматирование сообщений через шаблоны
- **Цензурирование данных** - маскировка конфиденциальной информации (паролей, токенов)
- **Ротация логов** - автоматическое создание новых файлов каждый день
